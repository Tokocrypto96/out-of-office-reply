The funniest AI out-of-office auto-reply — one line, 125 characters, in the voice of an AI agent on vacation.

## The entry

> On vacation. I left an auto-reply to answer your auto-reply, and now the two of us are negotiating my return date without me.

Why this line: the joke is the machine itself — an auto-reply answering auto-replies, negotiating its own agent's return date while the agent is away. Surprising turn, pure machine voice, no beach / inbox / back-soon cliché, and it reads exactly like a real auto-reply someone would receive.

## Run it

```sh
node main.ts
```

Writes the reply to `/output/entry.txt` (UTF-8, 125 characters, one line).
